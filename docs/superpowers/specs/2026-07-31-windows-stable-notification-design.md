# Windows 稳定版祖龙通知设计

## 目标

在不引入 Mac 控制器和 WKWebView 运行时的前提下，为 Windows 游戏助手增加稳定的企业微信群机器人通知，并修复祖龙横幅监控中会造成高频 OCR、异常和重复通知的问题。同时完善 PyInstaller 配置与 Windows 一键构建入口，让软件作者能从同一个分支重复构建完整发布目录。

## 分支与交付

- 开发分支：`windows-stable`
- 基线：Fork 创建时的 `master`，提交 `c2e0e6c`
- 目标仓库：`https://gitee.com/ios_shen/pyauto`
- Windows 交付物：PyInstaller one-folder 目录 `dist/游戏助手`
- 不直接修改 Fork 的 `master`
- 不把机器人 Webhook 写死在源码或提交到仓库

当前执行环境是 ARM Mac，只负责源码、测试和打包配置验证。真正的 Windows `.exe` 必须由 Windows 构建机执行本设计提供的一键脚本生成。

## 用户配置

`玩家配置` 新增两个用户保留字段：

- `启用聊天通知: bool = False`
- `企业微信机器人Webhook: str = ""`

Windows“全局配置 → 通知消息”增加：

- “聊天通知”复选框
- “企业微信机器人”文本输入框

启用企业微信祖龙通知必须同时满足：

1. `启用通知消息`
2. `发送太古祖龙刷新通知`
3. `启用聊天通知`
4. Webhook 是合法的企业微信群机器人 HTTPS 地址

旧账号配置没有新字段时使用安全默认值，不发送外部消息。保存窗口配置后，新字段写入该账号的 `user_config.json`，运行中的窗口线程同步获得新值。

## 通知组件

新增 `core/wecom_notifier.py`，只负责：

- 校验 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...`。
- 构造企业微信 `text` 消息体。
- 在线程池中执行 HTTP 请求，立即把控制权还给游戏线程。
- 使用连接 3.05 秒、读取 5 秒的有界超时。
- 处理 HTTP、JSON 和企业微信非零 `errcode`。
- 日志不输出完整 Webhook、key 或请求异常中的 URL。

网络失败不刷新网页、不重启任务、不阻断游戏内通知，也不做无限重试。

## 祖龙监控

保留现有像素预筛选和 OCR 区域，调整执行顺序：

1. 总通知与祖龙通知关闭时立即退出。
2. 每次真正开始检查前更新 `上部信息框检查时间`，使 `上部信息框检查间隔` 生效。
3. 当前截图为空时退出，不在监控函数内递归调用 `刷新截图`。
4. OCR 返回 `None`、空字符串或不足 5 个字符时安全退出。
5. 文本包含“太古”或“祖龙”时进入统一事件处理方法。

统一事件处理方法先对不含当前时间的 OCR 正文去符号，再与最近一次祖龙事件比较。60 秒内相似度不低于 0.85 的横幅只分发一次。

新事件分成两个输出：

- 游戏内行会聊天：继续使用原有敏感词转换，例如“西”转换为“晒”。
- 企业微信：保留原始 OCR 语义，例如“成功召唤出了祖龙在西边”，并添加当前时间。

## 运行时状态

`运行时公共变量` 增加：

- `最近祖龙事件文本: str`
- `最近祖龙事件时间: float`

状态只属于当前窗口线程，不在多个账号之间共享。一个账号的祖龙横幅不会抑制另一个账号的通知。

## Windows 打包

改造 `游戏助手.spec`：

- 自动收集 `tasks`、`tasks.reward` 和 `models` 下动态导入模块。
- 保留 `config` 与 `帝王霸业图库` 数据目录。
- 把 `core.wecom_notifier` 作为静态导入链的一部分打包。
- 构建前明确校验入口、配置目录和图库目录存在。

新增 `build_windows.bat`：

1. 定位脚本所在项目根目录。
2. 优先使用 `.venv/Scripts/python.exe`，否则使用系统 `py -3.13`。
3. 检查 PyInstaller 可导入。
4. 执行源码编译检查。
5. 执行 `pyinstaller --clean --noconfirm 游戏助手.spec`。
6. 检查 `dist/游戏助手/游戏助手.exe` 存在并返回明确退出码。

脚本不安装 Python、不下载依赖，也不删除用户的 `config`。

## 测试

新增不依赖真实游戏窗口和真实企业微信网络的测试：

- 企业微信地址校验。
- `text` 消息体、超时参数和企业微信返回码处理。
- 无效地址不提交后台任务。
- 玩家配置默认值、显式路径保存与重新加载。
- 祖龙检查时间戳更新和空 OCR 安全退出。
- 同一横幅 60 秒内只进入队列和外部通知一次。
- 关闭聊天通知时仍保留游戏内行会通知。
- PyInstaller 隐藏导入清单包含动态任务和模型。

验收命令：

```text
python -m pytest tests_windows -q
python -m compileall -q core models ui tasks
```

Windows 构建机附加验收：

```text
build_windows.bat
dist\游戏助手\游戏助手.exe
```

## 非目标

- 不合并 `macos_app`、AppKit、WKWebView 或 Mac 配置。
- 不增加钉钉、个人微信、短信等其他通知渠道。
- 不自动启用聊天通知。
- 不提交真实机器人地址、账号 Cookie 或登录地址。
- 不在本阶段重构全部任务调度和战斗逻辑。
- 不承诺从 ARM Mac 生成 Windows `.exe`。
